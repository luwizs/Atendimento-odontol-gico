# Sistema de Atendimento Odontológico

Sistema web para gerenciamento de atendimento odontológico.

## Tecnologias

### Frontend
- React
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express

### Banco de dados
- PostgreSQL

## Funcionalidades

- Cadastro de pacientes
- Login
- Agendamento de consultas
- Visualização de consultas
- Cancelamento de consultas
- Assistente de IA

 Em desenvolvimento
